# Dashboard-Vendas-Projeto-DIO
Atividade do Bootcamp Santander Excel com Claude. Dashboard simples de planilha de vendas.

A imagem mostra um painel (*dashboard*) de vendas de assinaturas da **Xbox Game Pass** para o período de 01/01/2024 a 31/12/2024.

Os principais dados apresentados são:

* **EA Play Season Pass:** R$ 600 em vendas.


* **Minecraft Season Pass:** R$ 940 em vendas.


* **Vendas com Xbox Game Pass (Yes):** R$ 1.634,00.


* **Vendas sem Xbox Game Pass (No):** R$ 120,00.



Na barra lateral esquerda, há uma mensagem de boas-vindas para "Fulana" e um filtro selecionado para o tipo de assinatura **Anual** (*Annual*).
